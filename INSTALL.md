# Installation Instructions

## NOVA Convert — Windows Desktop Edition

NOVA Convert is distributed exclusively as a single, self-contained Windows setup executable:

```
NOVA-Convert-Setup.exe
```

---

## Standard Installation Steps

1. **Download the Setup Package**:
   Locate `NOVA-Convert-Setup.exe` in the `dist\` release folder.

2. **Run the Installer**:
   Double-click `NOVA-Convert-Setup.exe`.
   - The setup wizard will guide you through the installation process.
   - You can choose to create a Desktop shortcut.
   - The application installs by default into:
     ```
     C:\Program Files\NOVA Software\NOVA Convert
     ```
     (or user-local Program Files if run without administrator elevation).

3. **Launch the Application**:
   - Launch from the Windows Start Menu under **NOVA Software → NOVA Convert**.
   - Or launch from the desktop shortcut if enabled.

4. **Bundled Engines**:
   All core conversion engines (including ImageMagick and FFmpeg) are bundled directly inside the installation package. No additional manual downloads are required.

---

## Uninstallation

To uninstall NOVA Convert:
1. Open Windows **Settings → Apps → Installed apps**.
2. Search for **NOVA Convert**.
3. Click **Uninstall**.
4. All application binaries and Start Menu shortcuts will be cleanly removed.
