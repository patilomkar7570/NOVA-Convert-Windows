# Privacy Policy

**NOVA Convert — Windows Desktop Edition**  
*Last Updated: 2026*

NOVA Software is committed to complete user privacy. NOVA Convert is an offline-first desktop application designed with zero data collection.

---

## 1. Zero Cloud Uploads

NOVA Convert processes all files entirely on your personal computer. Your documents, images, audio, video files, spreadsheets, e-books, and archives are never uploaded to any remote server, cloud storage, or external API.

## 2. No Accounts or Registrations

You do not need to create an account, register, or provide personal details to install and use NOVA Convert.

## 3. No Telemetry or Usage Tracking

NOVA Convert does not contain:
- Telemetry trackers.
- Analytics frameworks.
- Crash reporting beacons.
- Ad tracking scripts.
- Behavioral surveillance code.

## 4. Local Conversion History

The application maintains a local conversion history stored in an SQLite database located in your user application data folder:

```
%LOCALAPPDATA%\NOVA Convert\conversion_history.db
```

This database remains solely on your device. You can clear this history at any time from within the application interface using the **Clear History** button.

## 5. Network Access

The only optional network request NOVA Convert will ever perform is a version check against the official release endpoint when enabled in Settings. Update checks transmit no user data, hardware identifiers, or personal information.
